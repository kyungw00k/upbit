# [안내] 포켓(Pocket) 기능 및 신규 API 출시 안내

안녕하세요. 업비트 개발자센터입니다.

업비트 계정 내 자산을 목적별로 나누어 관리할 수 있는 **'포켓(Pocket)'** 기능 및 관련 API가 새롭게 출시되었습니다.

**'포켓'**&#xC740; 업비트 계정 안에서 자산을 목적별로 나누어 투자하고 관리할 수 있는 기능입니다. 기본으로 제공되는 메인포켓 외에도, 필요에 따라 서브포켓을 추가로 만들 수 있습니다.

상세한 신규 API 명세 및 업데이트 내용은 아래를 참고해 주시기 바랍니다.

<br />

### 1. 주요 업데이트 특징

* **자산 분리 운영:** 서브포켓 생성 시, 권한에 따라 자산 이전 및 독립적인 잔고 조회가 가능합니다.
  * 메인포켓 : 업비트 계정을 만들 때 기본으로 제공되는 기본 포켓입니다. 외부 입출금을 포함한 계정의 기본 거래를 할 수 있고, 계정 내 전체 포켓을 관리할 수 있는 권한을 받을 수 있습니다.
  * 서브포켓 : 특정 목적에 따라 사용자가 추가로 만드는 포켓입니다. API Key에 부여된 권한 안에서 독립적으로 동작하며, 외부 입출금은 제한됩니다.
* **포켓별 API Key 관리:** 각 포켓(서브포켓 포함)마다 별도의 API Key를 발급하고 권한을 부여할 수 있습니다. 포켓별 발급 가능한 권한은<Anchor target="_blank" href="https://docs.upbit.com/kr/reference/pocket-overview"> '포켓(Pocket)'</Anchor> 문서에서 확인하실 수 있습니다.

<br />

### 2. 신규 추가 API 목록

EXCHANGE API 내에 포켓 관리를 위한 신규 엔드포인트들이 추가되었습니다.

**포켓 정보 및 잔고 관리**

* **포켓 정보 조회**
  * 사용자가 보유한 전체 포켓(메인포켓 및 서브포켓)의 목록과 각 포켓의 기본 정보를 조회합니다.
* **서브포켓 잔고 조회**
  * 지정한 서브포켓에 보관되어 있는 디지털 자산 및 원화의 상세 잔고(전체 보유 수량, 주문 가능 수량 등)를 조회합니다.
* **포켓별 API Key 목록 조회**
  * 특정 포켓에 할당된 API Key의 목록과 각 Key에 부여된 기능 권한을 조회합니다.

**자산 이전 (Transfer)**

* **메인포켓 자산 이전**
  * 메인포켓의 권한을 사용하여 계정 내의 포켓 간(메인포켓 ↔ 서브포켓, 또는 서브포켓 간) 자산을 이전시킵니다.
* **메인포켓 자산 이전 목록 조회**
  * 메인포켓 권한으로 실행된 전체 자산 이전 내역을 조회합니다.
* **서브포켓 자산 이전**
  * 해당 서브포켓의 권한을 사용하여 서브포켓 내의 자산을 다른 포켓으로 이동시킵니다.
* **서브포켓 자산 이전 목록 조회**
  * 특정 서브포켓을 기준으로 발생한 자산 이전 내역을 조회합니다.

### 유의사항

* 포켓별 API를 원활하게 사용하기 위해서는 각 서브포켓의 용도에 맞는 API Key를 신규로 발급받아 적용하셔야 합니다.
* 각 API의 상세한 요청 파라미터 및 응답 모델은 업비트 개발자센터의 \[API Reference > EXCHANGE API > 포켓(Pocket)] 문서를 확인해 주시기 바랍니다.
* 가상자산 서비스 이용 전 관련 약관, 가상자산 거래 전 백서 등 설명자료를 통해 구체적인 내용을 확인하시기 바랍니다.
