# [안내] ‘출금 안심차단’ 기능 추가

안녕하세요, 업비트 개발자센터 입니다.

API Key 출금 권한을 더 안전하게 관리할 수 있는 ‘출금 안심차단’ 기능이 새롭게 추가됐어요. API Key별로 출금을 직접 잠그고 풀 수 있어, 필요한 만큼만 안전하게 관리할 수 있습니다.

### 적용 안내

* **적용 일자** : 2026-07-09 (목) 15:00 예정
* **적용 서비스** : 업비트 API

***

### ‘출금 안심차단’이란?

\*\*‘출금 안심차단’\*\*은 출금 권한이 있는 API Key의 출금을 기본적으로 막아두고, 회원님이 업비트 모바일 앱에서 직접 해제했을 때만 출금할 수 있도록 하는 보안 기능입니다.

출금 안심차단은 API Key마다 따로 적용되며, 하나의 API Key에서 출금 안심차단을 해제해도 다른 API Key에는 영향을 주지 않습니다.

**출금 안심차단은 2026년 7월 9일(목) 15:00부터 적용될 예정으로&#x20;**&#x41;PI Key 발급 시점에 따른 적용 방식은 아래 표를 확인해 주시길 바랍니다.

| 발급 시점                                        | 해지 필요 여부                                                            |
| -------------------------------------------- | ------------------------------------------------------------------- |
| 2026-07-09 (목)<br />15:00 **이후** 발급한 API Key | **출금 권한이 있으면 자동으로 적용됩니다.**<br />출금 필요 시 모바일 앱에서 출금 안심차단 해제하시길 바랍니다. |

### 출금 안심차단 해지 방법

API Key마다 처음 한 번만 해제하면, 다시 잠그기 전까지 그 API Key로 계속 출금할 수 있습니다.

* **이용 경로 : \[업비트 모바일 앱 > 더보기 > 인증/보안 > Open API 관리]**
* 메뉴가 보이지 않으면 앱을 최신 버전으로 업데이트해 주시길 바랍니다. ### 자주 묻는 질문

**Q. 새 API Key를 만들 때마다 매번 해제해야 하나요?**

* 출금 권한이 있는 API Key를 새로 발급할 때만 해당됩니다.
* API Key마다 최초 1회만 해제하면 되고, 출금할 때마다 해제할 필요는 없습니다.<br />1회 해제 후 다시 잠그기 전까지 API를 통한 출금이 가능합니다.

**Q. API로는 출금 안심차단을 해제할 수 없나요?**

* 네, API를 활용해 출금 안심 차단 해제는 불가능합니다.
* 해제는 업비트 모바일 앱에 로그인한 뒤에만 할 수 있습니다.&#x20;

***

### 유의사항

* 출금 안심차단으로 제한되는 것은 원화(KRW) 및 디지털 자산 출금입니다.
* API Key 발급 시 ‘출금하기’ 권한을 선택하면 원화 및 디지털 자산 출금 권한이 포함됩니다.
* 출금 안심차단 설정 전에 이미 접수된 출금은 그대로 진행됩니다.
* API Key 삭제는 \[업비트 PC > 마이페이지 > Open API 관리]에서 할 수 있습니다.
* 출금 안심차단은 개인 회원에게만 제공됩니다.
