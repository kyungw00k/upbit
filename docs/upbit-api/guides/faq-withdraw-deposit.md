# 입출금 관련 문의

입출금과 관련한 자주 묻는 질문 모음입니다.

### 바이낸스에서 업비트로 BCH 출금 시 트래블룰 검증에 실패합니다.

* 업비트는 Legacy 주소가 아닌 CashAddr를 지원하고 있습니다. 바이낸스에서 업비트로 출금 진행 시 CashAddr 앞에 `bitcoincash:` 제외하고 주소만 입력해 주세요.<br />예) 업비트 입금주소: bitcoincash:qrs123xxxxx<br />     바이낸스 출금 주소 입력란: qrs123xxxxx

<br />

### **출금 안심차단은 어디서 해지 가능한가요?**

* 업비트 모바일 앱에 로그인 완료 후 \[더보기 > 인증/보안 > Open API 관리 > 활성] 페이지에서 차단을 해지할 Key를 선택해<br />안심차단을 해지해주세요.

  ![](https://files.readme.io/7d85b8a9bfc0045ac2fad70487250bf04b4026a89094c6f8e81a015ea54e16fa-withdraw_safety_lock.png)

<br />

### 출금 안심차단 출금 차단 범위는 어디까지인가요?

* 원화 및 디지털 자산 모두 출금이 불가능합니다.
