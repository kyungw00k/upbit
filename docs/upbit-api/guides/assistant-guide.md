# 업비트 어시스턴트 이용 안내

업비트 어시스턴트는 업비트 Open API 개발 문서를 보다 빠르고 효율적으로 탐색하고 활용할 수 있도록 지원하는 기능입니다.

## 소개

업비트 어시스턴트는 개발자의 편의 향상과 학습 보조를 목적으로 제공됩니다.\
법적, 재정적, 투자적 자문을 제공하지 않으며, 특정 디지털 자산에 대한 추천이나 권유로 해석될 수 없습니다.

<br />

## 지원 범위

업비트 어시스턴트는 다음과 같은 작업을 지원합니다.

* Upbit Open API 관련 질의 및 기본 사용 예시 안내
* API 응답, 에러 코드, WebSocket, 인증 등 문서 검색
* 개발자센터 내 가이드 문서, 용어집, 예제 코드 확인

포함되는 내용:

* API Key 발급 가이드, 주요 에러 코드 등 FAQ
* 시세 조회, 지표 산출, 주문 생성 및 관리 관련 튜토리얼
* 개발 문서 예제 및 응답 코드
* 문서 기반 예제 코드의 누락 또는 간단한 오류 검증

<br />

## 답변 불가 범위

다음 항목에 대해서는 답변을 제공하지 않습니다.

* 개발자센터에서 지원하지 않는 외부 문서 또는 서비스
* 사용자 맞춤형 코드 생성 요청
* 개발 문서와 직접 관련이 없는 일반적 또는 비기술적 질문

<br />

## 이용 방법

① 업비트 개발자센터 우측 하단의 어시스턴트 아이콘을 클릭합니다.

② Upbit API 사용 방법, 엔드포인트, 응답 구조 등에 대한 질문을 자연어로 입력합니다.

③ 답변에 포함된 문서 링크를 통해 관련 가이드로 이동할 수 있습니다.

질문 예시:

* 주문 API에서 uuid는 어떤 용도로 사용되나요?
* WebSocket 체결 데이터 예시를 보여주세요.
* Access Key 인증 방식이 궁금합니다.

<br />

## 이용 시 유의사항

* 어시스턴트의 답변은 참고용으로만 활용해야 합니다.
* 서비스화, 상업적 활용, 재배포는 Open API 이용약관에 위반될 수 있습니다.
* API Key, 토큰, 계정 정보 등 민감한 데이터는 입력하지 않아야 합니다.
* 해당 정보는 수집되지 않으며, 입력 시 보안 위험이 발생할 수 있습니다.

자세한 내용은 아래 문서를 참고하세요.\

## 참고

업비트 어시스턴트는 현재 베타(Beta) 버전으로 제공되며, 기능 개선과 문서 범위 확대가 예정되어 있습니다.
