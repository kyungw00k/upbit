# 지표 정의

Upbit Strategy Toolkit이 제공하는 기술적 지표 15종의 정의, 출력 키, 파라미터, 활용 방법을 정리했습니다.

Upbit Strategy Toolkit이 제공하는 기술적 지표 15종의 정의·출력 키·파라미터·활용 방법을 정리한 문서입니다. 출력 키(ref)와 파라미터는 실제 구현(`core/indicators.py`) 기준입니다.

> 모든 지표는 과거 데이터 기반 참고 도구이며, 미래 수익을 보장하지 않습니다.

## 지표 한눈에 보기

| 지표         | type              | 분류      | 한 줄 설명               |
| ---------- | ----------------- | ------- | -------------------- |
| 이동평균       | `moving_average`  | 추세      | 일정 기간 평균 가격선         |
| 볼린저 밴드     | `bollinger_bands` | 변동성     | 이동평균 ± 표준편차 밴드       |
| 엔벨로프       | `envelopes`       | 변동성     | 이동평균 ± 고정 비율 밴드      |
| 일목균형표      | `ichimoku_cloud`  | 추세      | 다중 선·구름대로 추세/지지저항    |
| RSI        | `rsi`             | 모멘텀     | 과매수·과매도 강도 (0–100)   |
| MACD       | `macd`            | 추세/모멘텀  | 두 EMA 차이로 모멘텀 전환 포착  |
| ATR        | `atr`             | 변동성     | 평균 진폭(변동성 크기)        |
| 스토캐스틱(슬로우) | `stochastic_slow` | 모멘텀     | 기간 내 위치 + 평활화        |
| 윌리엄스 %R    | `williams_r`      | 모멘텀     | 고점 대비 현재 위치 (-100–0) |
| ADX        | `adx`             | 추세 강도   | 추세의 강도(방향 무관)        |
| OBV        | `obv`             | 거래량     | 거래량 누적으로 매집/분산       |
| CCI        | `cci`             | 모멘텀     | 평균가 대비 이탈 정도         |
| 스토캐스틱 RSI  | `stochastic_rsi`  | 모멘텀     | RSI에 스토캐스틱을 다시 적용    |
| MFI        | `mfi`             | 거래량/모멘텀 | 거래량 가중 RSI           |
| 이격도        | `disparity`       | 추세      | 가격이 이동평균에서 벗어난 비율    |

## 추세 지표

### 이동평균 (Moving Average) — `moving_average`

**정의** — 일정 기간의 종가 평균을 이은 선. 가격의 노이즈를 줄여 추세 방향을 보여준다.

**계산** — SMA(단순)는 기간 내 종가의 산술평균. EMA(지수)는 최근 값에 더 큰 가중치를 둔 평균.

| 출력 키    | 의미     |
| ------- | ------ |
| `value` | 이동평균 값 |

**주요 파라미터** — `type`(SMA/EMA), `period`(1–200)

**활용** — 가격이 이동평균 위/아래인지로 추세 판단. 단기·장기 두 선의 교차(골든크로스/데드크로스)를 진입·청산 신호로 사용.

**전략 예시** — sma5가 sma20을 상향 돌파(cross\_above)하면 매수.

<br />

### 일목균형표 (Ichimoku Cloud) — `ichimoku_cloud`

**정의** — 전환선·기준선·후행스팬·선행스팬 2개로 추세, 모멘텀, 지지·저항을 한 번에 보는 복합 지표. 선행스팬 1·2 사이 영역이 "구름대".

| 출력 키         | 의미                 |
| ------------ | ------------------ |
| `Conversion` | 전환선 (단기 균형)        |
| `Base`       | 기준선 (중기 균형)        |
| `Lagging`    | 후행스팬 (현재가를 과거로 이동) |
| `Leading1`   | 선행스팬 1 (구름 상·하단)   |
| `Leading2`   | 선행스팬 2 (구름 상·하단)   |

**주요 파라미터** — `conversion`(9), `base`(26), `leading_span2`(52)

**활용** — 가격이 구름 위면 상승 추세, 아래면 하락 추세. 전환선이 기준선을 상향 돌파하면 매수 신호로 본다.

<br />

### 이격도 (Disparity) — `disparity`

**정의** — 현재가가 이동평균에서 얼마나 떨어져 있는지를 백분율로 나타낸 값. 100이면 이동평균과 일치, 100보다 크면 위, 작으면 아래.

**계산** — (현재가 ÷ N기간 이동평균) × 100

| 출력 키      | 의미       |
| --------- | -------- |
| `disp_5`  | 5기간 이격도  |
| `disp_10` | 10기간 이격도 |
| `disp_20` | 20기간 이격도 |
| `disp_60` | 60기간 이격도 |

**주요 파라미터** — `periods`(기본 5, 10, 20, 60)

**활용** — 이격도가 과도하게 높으면 단기 과열(되돌림 가능), 낮으면 과매도로 본다.

***

## 변동성 지표

### 볼린저 밴드 (Bollinger Bands) — `bollinger_bands`

**정의** — 이동평균(중심선) 위아래로 표준편차의 배수만큼 띄운 상·하단 밴드. 변동성이 커지면 밴드가 벌어지고 작아지면 좁아진다.

**계산** — 중심선 = N기간 이동평균. 상·하단 = 중심선 ± (표준편차 × 배수).

| 출력 키        | 의미         |
| ----------- | ---------- |
| `bb_upper`  | 상단 밴드      |
| `bb_middle` | 중심선 (이동평균) |
| `bb_lower`  | 하단 밴드      |

**주요 파라미터** — `period`(20), `multiplier`(2.0)

**활용** — 가격이 하단에 닿으면 과매도, 상단에 닿으면 과매수로 보는 평균회귀 전략. 밴드 폭 축소(스퀴즈) 후 확장은 변동성 돌파 신호.

<br />

### 엔벨로프 (Envelopes) — `envelopes`

**정의** — 이동평균 위아래로 고정 비율(%)만큼 띄운 밴드. 볼린저 밴드가 표준편차를 쓰는 것과 달리, 일정 퍼센트를 사용한다.

| 출력 키     | 의미         |
| -------- | ---------- |
| `upper`  | 상단 밴드      |
| `center` | 중심선 (이동평균) |
| `lower`  | 하단 밴드      |

**주요 파라미터** — `period`(20), `percent`(6.0)

**활용** — 가격이 상·하단을 벗어나면 과열·과매도로 판단하는 채널 전략에 사용.

<br />

### ATR (Average True Range) — `atr`

**정의** — 일정 기간 동안의 평균 "진폭"을 나타내는 변동성 지표. 방향이 아니라 변동의 크기를 측정한다.

**계산** — True Range(고가-저가, 전일종가와의 갭 포함)의 N기간 평균.

| 출력 키  | 의미    |
| ----- | ----- |
| `atr` | 평균 진폭 |

**주요 파라미터** — `period`(14)

**활용** — 손절 폭이나 포지션 크기를 변동성에 맞춰 조정할 때 사용. ATR이 크면 변동성이 큰 구간.

<br />

## 모멘텀 지표

### RSI (Relative Strength Index) — `rsi`

**정의** — 일정 기간 상승폭과 하락폭의 비율로 가격 모멘텀의 강도를 0–100으로 나타낸다.

**계산** — 100 − (100 ÷ (1 + 평균상승폭/평균하락폭)).

| 출력 키         | 의미                   |
| ------------ | -------------------- |
| `rsi`        | RSI 값 (0–100)        |
| `rsi_signal` | RSI 시그널선 (RSI의 이동평균) |

**주요 파라미터** — `period`(14), `signal_period`(9), `signal_type`(EMA)

**활용** — 통상 70 이상 과매수, 30 이하 과매도로 본다. RSI가 시그널선을 교차하는 시점을 진입·청산에 활용.

**전략 예시** — RSI가 30 이하로 떨어지면(`lte 30`) 매수.

<br />

### MACD (Moving Average Convergence Divergence) — `macd`

**정의** — 단기 EMA와 장기 EMA의 차이로 추세 전환과 모멘텀을 포착한다.

**계산** — MACD선 = 단기 EMA − 장기 EMA. 시그널선 = MACD선의 EMA. 히스토그램 = MACD선 − 시그널선.

| 출력 키          | 의미           |
| ------------- | ------------ |
| `macd`        | MACD선        |
| `macd_signal` | 시그널선         |
| `histogram`   | MACD선 − 시그널선 |

**주요 파라미터** — `fast`(12), `slow`(26), `signal_period`(9)

**활용** — MACD선이 시그널선을 상향 돌파하면 매수, 하향 돌파하면 매도. 히스토그램의 부호 전환도 신호로 사용.

### 스토캐스틱 (Slow Stochastic) — `stochastic_slow`

**정의** — 최근 기간의 고저 범위 안에서 현재가가 어디에 위치하는지를 0–100으로 나타내고, 이를 평활화한 지표.

| 출력 키     | 의미            |
| -------- | ------------- |
| `slow_k` | %K (평활화된 위치)  |
| `slow_d` | %D (%K의 이동평균) |

**주요 파라미터** — `period`(9), `k_period`(3), `d_period`(3)

**활용** — 통상 80 이상 과매수, 20 이하 과매도. %K가 %D를 교차하는 지점을 신호로 사용.

<br />

### 윌리엄스 %R (Williams %R) — `williams_r`

**정의** — 최근 기간 고점 대비 현재가의 위치를 -100 \~ 0으로 나타낸다. 스토캐스틱과 유사하나 척도가 음수.

| 출력 키         | 의미            |
| ------------ | ------------- |
| `williams_r` | %R 값 (-100–0) |

**주요 파라미터** — `period`(14)

**활용** — -20 이상이면 과매수, -80 이하면 과매도로 본다.

<br />

### CCI (Commodity Channel Index) — `cci`

**정의** — 평균가가 일정 기간 평균에서 얼마나 벗어났는지를 측정한다. 0을 중심으로 진동.

| 출력 키         | 의미       |
| ------------ | -------- |
| `cci`        | CCI 값    |
| `cci_signal` | CCI 시그널선 |

**주요 파라미터** — `period`(14), `signal_period`(9), `signal_type`(EMA)

**활용** — 통상 +100 이상 과매수, -100 이하 과매도. 0선 돌파를 추세 전환 신호로도 사용.

<br />

### 스토캐스틱 RSI (Stochastic RSI) — `stochastic_rsi`

**정의** — RSI 값에 다시 스토캐스틱 공식을 적용한 지표. RSI보다 민감하게 과매수·과매도를 잡는다.

| 출력 키          | 의미            |
| ------------- | ------------- |
| `stoch_rsi_k` | %K            |
| `stoch_rsi_d` | %D (%K의 이동평균) |

**주요 파라미터** — `rsi_period`(14), `stoch_period`(14), `k_period`(3), `d_period`(3)

**활용** — RSI보다 신호가 잦으므로 단기 매매에 쓰되 노이즈에 주의. %K·%D 교차를 신호로 사용.

***

## 추세 강도 지표

### ADX (Average Directional Index) — `adx`

**정의** — 추세의 방향이 아니라 강도를 측정한다. +DI·-DI는 상승/하락 방향의 힘.

| 출력 키      | 의미             |
| --------- | -------------- |
| `adx`     | 추세 강도          |
| `adx_pdi` | +DI (상승 방향 강도) |
| `adx_mdi` | -DI (하락 방향 강도) |

**주요 파라미터** — `period`(14)

**활용** — 통상 ADX 25 이상이면 추세가 강하다고 본다. +DI가 -DI 위면 상승 우위. 추세 추종 전략의 필터로 자주 쓴다.

***

## 거래량 지표

### OBV (On-Balance Volume) — `obv`

**정의** — 종가가 오른 날의 거래량은 더하고 내린 날은 빼서 누적한 값. 거래량으로 매집/분산을 본다.

| 출력 키         | 의미       |
| ------------ | -------- |
| `obv`        | OBV 누적값  |
| `obv_signal` | OBV 시그널선 |

**주요 파라미터** — `signal_period`(10), `signal_type`(SMA)

**활용** — 가격은 횡보하는데 OBV가 오르면 매집(상승 선행) 신호로 해석. 가격과 OBV의 다이버전스에 주목.

### MFI (Money Flow Index) — `mfi`

**정의** — RSI에 거래량을 가중한 지표. "거래량까지 반영한 RSI"로 0–100 범위.

| 출력 키  | 의미            |
| ----- | ------------- |
| `mfi` | MFI 값 (0–100) |

**주요 파라미터** — `period`(14)

**활용** — 통상 80 이상 과매수, 20 이하 과매도. 거래량을 반영해 RSI보다 자금 흐름을 잘 잡는다는 평.

***

## 참고

* 각 지표를 조건식에서 어떻게 참조하는지(출력 키(ref))와 설정할 수 있는 파라미터의 전체 목록은 기술 레퍼런스의 "지원 지표" 항목에서 확인할 수 있습니다.
* 본 문서에서 소개한 활용법은 일반적으로 통용되는 해석일 뿐, 정해진 정답이 아닙니다. 같은 지표라도 종목·기간·타임프레임에 따라 결과가 크게 달라집니다.
* 어떤 지표도 미래 가격을 예측하지는 못합니다. 반드시 백테스트로 가설을 검증한 뒤, 그 결과를 참고 자료로만 활용하세요.
