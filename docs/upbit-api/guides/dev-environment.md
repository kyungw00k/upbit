# 개발환경 설정

Upbit API를 사용하기 위한 개발 환경 설정 가이드입니다. Python, Java, Node.js 환경에서 API를 호출하기 위한 기본 준비 과정을 안내합니다.

## 시작하기

Upbit API를 처음 사용하는 경우, 다음 순서로 진행하는 것을 권장합니다.

① 사용할 개발 언어 선택 (Python, Java, Node.js)

② 개발 환경 설정 및 필수 라이브러리 설치

③ API Key 발급 및 인증 방식 이해

④ REST API 또는 WebSocket 호출 테스트

각 언어별 문서를 통해 환경 설정부터 API 호출까지 단계적으로 진행할 수 있습니다.

<br />

## 언어별 개발 환경 설정

사용할 언어를 선택하여 개발 환경 설정을 진행하세요.

* [Python 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-python)\
  Python 설치, 가상 환경 구성, REST API 및 WebSocket 호출을 위한 라이브러리 설정을 포함합니다.
* [Java 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-java)\
  JDK 및 개발 도구 설정, HTTP 클라이언트 라이브러리 구성, API 호출을 위한 기본 환경을 포함합니다.
* [Node.js 개발 환경 설정](https://docs.upbit.com/kr/docs/dev-environment-nodejs)\
  Node.js 설치, 패키지 관리, REST API 및 WebSocket 호출을 위한 라이브러리 설정을 포함합니다.
