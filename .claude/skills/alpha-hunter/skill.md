## 분석 프레임워크

### 1. Rule-base 한계 분석
- RSI-2는 2025년 7월/12월 급락에 취약 (각 -1.1%, -1.2%)
- 순수 지표 기반으로는 시장 구조 변화 대응 불가
- 장기 횡보/하락장에서 수익 창출 어려움

### 2. LLM 도입 ROI 계산
```
LLM 호출 비용 (GLM API):
- 분석당 약 500 token × 0.01원/token = 5원/건
- 1일 6회 (4h마다) = 30원/일 = ~11,000원/년

추가 수익 필요:
- 330,000 × 2% = 6,600원/년
- LLM 비용 11,000원을 상회하려면 3.3% 이상 수익률 필요
```

### 3. 하이브리드 아키텍처 옵션

#### Option A: Rule-base 단독 (비용 0)
- 최적의 Rule-base 전략 조합
- 다중 시간프레임 확인 (4h 트렌드 + 1h 시그널)
- 목표: 연 3~5%

#### Option B: LLM 필터 (비용 ~11,000원/년)
- Rule-base 시그널 생성 → LLM이 뉴스/감정으로 필터링
- 급락 전 "공포" 감지하여 진입 차단
- 목표: 연 5~8% (필터로 손실 거래 30% 감소 시)

#### Option C: LLM 주도 (비용 ~50,000원/년)
- LLM이 모든 판단, Rule은 보조 지표만 제공
- 33만원 소자본에서는 비용이 수익 초과 → **비추천**

## 결론 도출 기준
