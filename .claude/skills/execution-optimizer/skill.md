# Execution Optimizer — 실행 최적화 스킬

## 최적화 대상 파라미터

### 포지션 사이징
| 옵션 | 비율 | 설명 |
|---|---|---|
| 보수적 | 10% | MDD 낮음, 수익도 낮음 |
| 중간 | 20% | 균형 |
| 공격적 | 30% | 현재 기본값 |
| 초공격 | 50% | MDD 높음, 수익 가능 |

### 트레일링 스탑 (ATR 배수)
| 배수 | 특성 |
|---|---|
| 1.0× | 타이트, 잦은 청산 |
| 1.5× | 균형 |
| 2.0× | 현재 기본값 |
| 3.0× | 느슨함, 긴 포지션 |

### 진입 확인
- **즉시**: 시그널 발생 즉시 진입
- **다음캔들**: 시그널 후 다음 캔들에서 방향 확인 후 진입
- **리트라이**: 진입 후 손절 시, 동일 방향 시그널 재발생 시 재진입

## 백테스트 방법
최고 전략을 기준으로 각 파라미터를 격자 탐색:
1. 포지션 × 트레일링 매트릭스 (4×4 = 16조합)
2. 각 조합에 대해 2024/2025 백테스트
3. Sharpe-like 지표로 순위 결정

## Sharpe-like 계산
```
sharpe = (연수익률 - 0.02) / MDD
```
- 0.02 = 무위험 수익률 (은행 이자)
- sharpe > 1.0 이면 우수
- sharpe < 0 이면 은행 이자보다 못함

## 출력
- 파라미터 × 성과 히트맵
- 최적 조합 추천
- 최적 vs 현재(30%, 2×ATR) 비교
